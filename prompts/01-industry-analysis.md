# Prompt: 行业适配分析

> 用途：让任何大模型（ChatGPT / Claude / Codex 等）为你的行业生成两线叙事策略。
> 使用方法：把下面的【】替换成你的信息，粘贴给任意 LLM。

---

## 输入模板

```text
我在【行业/城市】做【业务类型】。
核心卖点：【透明报价 / 自有团队 / 工艺标准 / 其他】。
我的性格：【稳重专业型 / 直接敢怼型 / 温和型 / 幽默型】。
我的目标：【老板IP + 员工矩阵 / 个人账号 / 企业账号】。

请用"日更100条方法论"为我生成行业适配分析，包含：
1. 行业天然优势（5条，适合短视频呈现）
2. 行业红线（✅/❌标记）
3. 两线叙事设计：软线（争议方向3条）+ 硬线（承接方式4条）
4. 交替节奏建议
```

## 输出示例（装修行业）

```markdown
### 行业天然优势
1. 强视觉冲击：装修前后对比、施工现场、工艺细节
2. 信息差巨大：消费者不懂装修，每个细节都是选题
3. 本地信任刚需：同城流量直接转化到店
4. 决策周期长：用户反复看、对比、收藏
5. 场景丰富：工地、材料市场、设计室、验收现场

### 两线叙事
软线（引流）：
- 反共识：半包比全包更贵，90%的人不知道
- 行业揭秘：装修公司利润到底多少？我交个底
- 消费者教育：这5个装修设计，设计师不会告诉你

硬线（承接）：
- 施工现场实拍：水电走线标准
- 工艺对比：我家工艺 vs 市面常见做法
- 设计效果展示：改造前后对比
- 客户反馈：入住照、验收记录
```

---

## 设计原则

- **软线必须有争议钩子**：反常识、反共识、行业揭秘、消费者教育
- **硬线必须有可视化证明**：实拍 > 口播，对比 > 描述
- **争议对事不对人**：说行业问题，不点名具体品牌
- **本地优势放大**：同城流量是最便宜的转化路径
