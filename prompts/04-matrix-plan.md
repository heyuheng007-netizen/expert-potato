# Prompt: 内容矩阵与4周起号计划

> 用途：生成完整的内容矩阵策略 + 4周起号执行计划。
> 使用方法：把【】替换成你的信息，粘贴给任意 LLM。

---

## 输入模板

```text
你是日更100条方法论教练。请为我生成内容矩阵和4周起号计划。

行业：【装修】
团队规模：【老板1人 + 设计师2人 + 施工2人】
目标：【日更20条：老板10条 + 员工10条】
平台：【抖音主冲 + 视频号辅发】
服务区域：【重庆本地】

请输出：
1. 每周起号计划（4周表格：时间 → 内容类型 → 条数 → 说明）
2. 每日发布节奏表（时段 → 老板IP → 设计师号 → 施工号）
3. 员工矩阵分工表
4. 每周验证重点
```


## 风险控制（必须提醒用户）

1. **同平台发布过多导致降权**：同账号 > 15条/天可能降权，多的分给员工号
2. **争议内容引发同行举报**：对事不对人，不点名
3. **员工拍摄意愿不足**：先从随手拍开始，不要求出镜
4. **内容质量下降**：建立选题库+脚本模板，批量备稿
5. **客户隐私泄露**：拍摄前征得同意，人脸打码

## 平台策略

| 平台 | 定位 | 内容策略 |
|------|------|----------|
| 抖音（主冲） | 流量主阵地 | 争议类+揭秘类首发，同城流量 |
| 视频号（辅发） | 私域+转介绍 | 故事+案例+日常，客户转发朋友圈 |
| 小红书（可选） | 种草+设计 | 设计师号主发，效果图+软装搭配 |

## 生成规则

1. 周计划必须用表格，标明每天时段、类型、条数
2. 每条风险必须给出解决方案
3. 节奏要符合"试水 → 加量 → 冲刺 → 固化"逻辑
4. 员工矩阵要区分岗位（设计/施工/销售），不给同质化任务
