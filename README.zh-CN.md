# 日更100条方法论

**面向 AI 辅助工作流的高频短视频内容创作系统方法论。**

> 把「日更100条」从一句口号变成一套可执行的 SOP。
> 服务三类人：老板/创始人做个人IP、员工跑内容矩阵、个人创作者批量起号。

[English](README.md) | [方法论详解](docs/methodology.md) | [口播模板](docs/templates.md)

---

## 为什么做这个项目

大多数中小企业知道要做短视频，但普遍卡在三件事：

- **老板不知道说什么** → 没有个人IP，没有信任背书，流量全靠投广告
- **员工不愿意出镜** → 没有内容矩阵，一个号 = 单点失败
- **创作者坚持不下去** → 发3条就停，永远到不了算法阈值

**日更100条方法论**用一套概率游戏回答一个核心问题：

> 如何低成本、持续地生产足够多「高质量 + 有品牌感」的内容，饱和覆盖算法、建立真实信任？

本仓库把这个方法论打包成 **AI 可用的 Prompt 框架**、**口播文案模板** 和 **可运行的示例生成器**——任何企业配合大模型（ChatGPT / Claude / Codex 等）即可直接落地，不需要专门养一支内容团队。

## 核心策略

| # | 策略 | 解决什么问题 |
|---|------|-------------|
| 1 | **高频轰炸**（数量换概率） | 不预测哪条会爆，用数量覆盖不确定性 |
| 2 | **两线叙事** | 软线（争议/钩子）引流量，硬线（工艺/案例）做转化 |
| 3 | **争议切入** | 穿透信息茧房；讨论 > 认同 |
| 4 | **矩阵思维** | 老板IP → 员工号 → 复制成功，分布式信任网络 |
| 5 | **N+1创新** | 比行业最先进水平多做一点点，而不是降价降质 |
| 6 | **SABCD品牌承接** | 争议引来的流量必须由品牌力接住 |
| 7 | **反向侵蚀风险** | 用争议之前，先知道它的边界 |

**5种口播模板** —— 反共识型 / 故事悬念型 / 方法论型 / 产品展示型 / 日常随记型。

## 快速上手

### 方式A —— 直接用 Prompt（零代码）

打开 [`prompts/`](prompts/) 下任意文件，粘贴给任意大模型：

```text
# 01-industry-analysis.md
我在重庆做本地装修公司。
核心卖点：透明报价、工艺标准、自有团队。
我的性格：稳重专业型。
→ 为我的行业生成两线叙事策略。
```

### 方式B —— 用 Python 生成脚本草稿

```bash
python src/generate_script.py --topic "半包比全包更贵" --type anti-consensus --duration 15
```

输出：结构化的口播草稿（钩子 → 正文 → 结尾行动），可直接开拍。
